# Prototipo de UI navegable

Abre `index.html` en Chrome/Edge. No requiere instalar nada ni conexión para su interfaz básica. Usa SVG locales y CSS, y ofrece demostraciones **en memoria** de inicio, ventas, fiados, corte, metas y pendientes. Los cambios se pierden al cerrar/actualizar y no se envían a ningún servidor.

**Muy importante:** NO ES UNA APP DE COBROS ni implementa pey/CoDi. El modo digital siempre se queda en **SOLICITUD SIMULADA / NO VERIFICADA**, y las cifras son exclusivamente un dataset ilustrativo independiente del proyecto real. No usar como fuente financiera ni conectar sin un backend auditado.

Este prototipo sirve para estudiar jerarquías, respuestas, microcopy y estructura DOM semántica, no para reemplazar el código existente.
