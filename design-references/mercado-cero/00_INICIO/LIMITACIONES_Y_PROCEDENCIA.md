# Procedencia, límites y verificaciones

**Fuente:** archivo adjunto al chat `image(7).png`, 1536×1024, PNG RGBA, composición AI raster. Se incluye una copia maestra íntegra. **No existe un archivo de diseño editable original disponible**, por lo que no es correcto prometer recuperación de tipografías, capas, logos o iconos exactos.

**Recortes PNG:** son regiones tomadas sin retoque de la imagen. Las imágenes de celulares tienen tamaño reducido: sirven para composición y estilo, no para transcribir cantidades o microcopy pixel por pixel.

**SVG originales:** diseño humano programático basado en la misma dirección de arte (verde, toldo, papel, barro). No son calcos de ilustraciones/personas, ni pertenecen a un paquete preexistente. Se incluyen como *base editable* adaptable y no se afirma equivalencia exacta con la imagen.

**Fotos y rostros:** esta entrega no reproduce el rostro de una persona real. Para producción, no utilizar retratos sintéticos como testimonios de comerciantes reales.

**Datos de la lámina:** todas las cifras, nombres de clientes, metas y datos de pagos de los mockups se tratan como ficticios. Revalidar cualquier nombre o texto distorsionado por generación de imágenes.

**Fuentes:** no se distribuyen archivos de fuentes. Propuesta: Fraunces para títulos, Inter para interfaz. Revisar licencias y política de alojamiento web antes de publicar.

**Paquete:** no contiene claves de API ni código privativo de pey; tampoco incluye configuración real de OpenCode ni código fuente del proyecto del usuario. Los tests adjuntos son *plantillas* que el equipo adapta al stack real.

**Riesgos:** las muestras de SVG/CSS solo se consideran listas para producción tras QA visual, contraste por combinación y controles keyboard/screen-reader. No se declara conformidad WCAG por instalar el kit.
