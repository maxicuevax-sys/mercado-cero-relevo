# Referencia de acceso suministrada por el usuario

`access-reference.png` es el archivo original recibido el 7 de noviembre de
2026 (941 × 1672 px). Se conserva sin editar. La pantalla usa exclusivamente
su ventana de ilustración (x24, y500, 894 × 395), recortada por CSS responsive.
Los textos, marca Trangui, formularios, iconos y botones son HTML/React; no se
usan los campos de la imagen como controles. El reloj y los indicadores del
teléfono de la referencia no se dibujan en la página web.

Si se entrega la ilustración original separada, reemplazar la imagen y quitar
el desplazamiento de recorte, conservando el resto de la composición.
